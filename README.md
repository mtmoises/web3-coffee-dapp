# ☕ Web3 Coffee DApp

Una aplicación descentralizada (DApp) minimalista para comprar cafés usando Ethereum. 

## 🛠️ Tecnologías usadas
- **Frontend:** HTML5, TypeScript, Vite
- **Web3:** Viem (para interactuar con la blockchain)
- **Smart Contracts:** Solidity (desplegado localmente con Foundry/Anvil)
- **Wallet:** MetaMask
